6 — Open before build

Decisions these mockups do not settle

Panel placement. Above the message body, as drawn, or floating at the right? Above survives Gmail markup changes better; floating is harder to miss. Decide in 4.3 against the real DOM.

Clear tier. Collapsed one-liner, as drawn, or nothing at all? A panel that says “fine” on every message gets ignored — and then it is ignored on the one that matters.

Dashboard authentication. An install token in a URL is not a login. Likely a read-only view scoped to the install, using the token the extension already holds. Needs deciding before 4.5.
