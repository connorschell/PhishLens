Scans by severity
These are operational counts, not model evaluation. Precision, recall and false-positive rate are measured against the held-out set in 02_Model/evaluate.py (WBS 2.1 and 5.5). The disagreement rate below is what users reported, which is a review signal — not measured error.
No subject, body or sender address appears here because the database stores none — a scan is identified by a salted fingerprint. Install ids are truncated to 8 characters: enough to group scans, not enough to identify an installation.
Marking an item reviewed records that a person looked at it. It does not relabel the scan or feed the model — feedback is a queue for WBS 2.4 calibration, never ground truth applied automatically.
